# 📥 OffTube

> Baixe vídeos do YouTube direto para o seu PC — sem navegador, sem complicação.

---

## ✨ O que é o OffTube?

**OffTube** é a melhor ferramenta desktop para Windows que permite baixar vídeos do YouTube de forma rápida e simples. Sem extensões de navegador, sem sites cheios de anúncio, sem enrolação.

Basta abrir, colar o link e baixar.

---

## 🚀 Como usar

1. **Execute** o arquivo `OffTube.exe`
2. **Cole** o link do vídeo do YouTube
3. **Escolha** a qualidade desejada
4. **Clique em baixar** e aguarde ☕

---

## 💻 Requisitos

| Item | Detalhe |
|------|---------|
| Sistema | Windows 10 ou superior |
| Arquitetura | 64-bit |
| Conexão | Internet ativa |

## 📦 Instalação

Nenhuma instalação necessária! O OffTube é portátil.

Basta fazer o download do `OffTube.exe` e executar diretamente.

---

## 🛠️ Problemas comuns

**O programa não abre?**
- Verifique se seu antivírus não está bloqueando o arquivo
- Execute como Administrador (botão direito → "Executar como administrador")

**O download falha?**
- Verifique sua conexão com a internet
- Confirme se o link do vídeo está correto e se o vídeo não é privado
- Se estiver dando erro de cookie, reinicia a internet que volta a funcionar. (Raro)
